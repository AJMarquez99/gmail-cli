# Audit: v1.0.0 release verification against live Gmail

**Date:** 2026-09-28 · **Build:** `release/v1.0.0` source install (`npm install -g .`), `gmail --version` → 1.0.0
· **Account:** the dedicated agent test account (default profile). All sends were addressed to the
account itself.

## Results

| Area | Check | Result |
|---|---|---|
| Diagnostics | `gmail doctor` | ✅ credentials, SMTP, IMAP ok |

The config file's content was compared against a backup taken before the config checks and was
unchanged afterwards (apart from the permission tightening).

## Follow-ups

- STORE-based writers (label add, mark read/unread, star/important on) still report the command's
  acceptance, not confirmed state — see `.ai/knowledge/architecture.md`.
- `[Google Mail]/…` localized system mailboxes are not supported (all system mailbox names are
  hardcoded as `[Gmail]/…`).
